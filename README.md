# yo-gi-oh

A **Yo-Gi-Oh** replica.  

### Controls:
Drag and drop cards by clicking them and dragging with you mouse.  
Interact with cards for example to attack by pressing them.  
Your goal is to make the opponent health reaches 0.
P.S. Some cards have abilities and their is even magic cards.

Built with:
[Godot Game Engine v4.6.stable](https://godotengine.org)

### Why I built this project:
I wanted to try creating a card game from scratch, so here we are.
